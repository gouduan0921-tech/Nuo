# 商业化与 DLC

版本：0.2 · 2026-10-01  
主责：钱可以为什么付、不可以为为什么付。首发按买断制作。支付开关默认关。验收底线见 `01` §6。

## 1. 首发卖什么

一份完整单机。文、声望、酿艺点、家曲都在玩法里循环。不设广告。不设能量。

豪华版若以后存在，只是外观包的捆绑，不提前解锁清酒、桂花或 4 级。

## 2. 可以卖的

开关 `payments` 打开之后，只允许这些商品：

| 商品 | 内容 |
|---|---|
| 封签与瓶型 | 颜色和网格。不改 `perDou`，不改基础价 |
| 院落外观 | `warm_kiln`、`porcelain_white` 的器物。仍走 `13` 的氛围上限 |
| 称呼与衣服 | 玩家外观。不改数值 |

季节主题包、新地区（北方黍米、西南酒）若要做，必须是新的品种和酒路行，走 `04`、`06`、`07` 的同一套规则，不能是「付费跳过一季」。

## 3. 不可以卖的

- 米、曲、桂花、文、声望、酿艺点、泉华。
- 缩短或跳过浸、蒸、发酵、窖。
- 消除瑕疵、提高成色百分比的道具。
- 赛季通行证里的产能、客流和配方。通行证若打开，里面只能是 §2 的外观。
- 广告换收成。

## 4. 接口

商品表 `iap.json` 默认不加载。字段只有 `id`、`kind`（`seal`、`bottle`、`style`、`outfit`）、`grantId`。  
`kind` 出现其他值时，加载失败。  
购买成功只解锁对应 `grantId`，不写钱，不写等级。

## 5. 验收

支付关闭时：

- 商店页不出现。
- 28 个酒坊日内仍能按 `04` §12 的路径升到 4 级。
- 甜酒酿和至少一条坛装酒路可以卖出。

见 `26`。

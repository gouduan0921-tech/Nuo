# 核心玩法循环与系统框架

版本：0.2 · 2026-10-01  
主责：场地、时间、天气、周节奏、批次流转、系统边界。数字见 `04`；工站规则见 `06`、`07`；销售见 `08`；字段见 `05`。

## 1. 场地

首发只有一进院子，叫酒坊院。北端是水田，南端朝河埠开门。玩家不能走出河埠。风格只换灯、坛、帘、柜，不换地形。

### 1.1 平面

灰盒以北为上。占地约 48 米（南北）× 28 米（东西），含水岸矮栏。尺寸可以偏一成，但邻接关系不能改。

```text
北   远河与对岸屋瓦（只可看）
     水田三块
     米囤 → 浸缸 — 蒸甑
                    檐廊（有顶，主路，通向南）
     摊席（东，无顶）           曲案（廊东）
     发酵房（廊西小间）         压榨 — 澄清槽
     酒窖（西，半地下入口，仍在同一场景）
南   调配案 + 前柜 — 河埠（老周、客人从这里来）
```

| 部位 | 约尺寸 | 顶 | 作用 |
|---|---|---|---|
| 水田 | 16 × 10 m | 露天 | 三块田。另留一条田埂空位给篇章 `plot_wild` |
| 米囤 | 3 × 2 m | 檐下 | 浸缸入口的米筐，上限见 `04` §3 |
| 浸缸、蒸甑 | 各约 4 × 4 m | 灶棚 | 浸完直接上甑 |
| 摊席 | 东侧 8 × 6 m | 无，见天 | 摊凉。雨天席收到檐下 |
| 曲案 | 廊东 | 廊檐 | 拌家曲 |
| 发酵房 | 廊西 6 × 5 m | 有顶 | 缸。窗口期缸沿亮一圈 |
| 压榨、澄清 | 廊西南 | 檐下 | 压榨后分酒路：清酒进槽，米酒可直接下窖 |
| 酒窖 | 西侧入口 | 窖顶不单独加载场景 | 坛装陈放。镜头推近即可，不切关卡 |
| 调配案 | 前柜后侧 | 店檐 | 桂花酿在这里加辅料 |
| 前柜 | 进深约 6 m | 店檐 | 展位朝南 |
| 河埠 | 门外约 4 m 可见 | 露天 | 客人、老周从这里来 |

甜酒酿在发酵房按短时出缸，不过压榨，直接装瓶去前柜或后仓。其余酒路必须经过压榨。

### 1.2 边界

- 东西是竹篱和水杉，篱外用邻屋粉墙封边。北界是田埂外的河，南界是河埠。
- 时令固定在夏末到秋初的一季。八个工时里，后两时是傍晚和入夜。没有第二层楼。酒窖是同一场景里的下沉一阶，不单独加载。

### 1.3 镜头与离屏

- 全院档沿檐廊至少同时看清三站。工站档对准该站锚点。
- 不在镜头里的站照常结算。画面只渲染可见站和当前特写，数据层保存全部批次。
- 布置不能占主路、田埂、摊席、展位、客人站位、缸前搅缸站位，见 `09`。

## 2. 时间

### 2.1 一天

一个酒坊日 8 个工时。没有互相锁住的阶段。工时 1–5 为昼，6 为傍晚，7–8 为入夜。入夜仍可蒸、可搅、可上窖；前柜在入夜不再来新客人，已经站在柜前的客人会把这次买卖说完。

```text
开坊：结算天气与预报、老周报价、批购板、当日氛围与客流、客人到达时刻
  → 8 个工时内，各站同时推进
  → 玩家随时收稻、组批、选酒路、派工、亲手蒸、搅缸、上柜
  → 收工（或工时走满）：水田结算、订单到期、开销、三行日结
  → 次日开坊，缸、窖、摊席、米囤和后仓都还在
```

### 2.2 推进

玩家按「推进」，时间走到最近的一个交接点停下：

- 某个计时站做完一批。
- 某缸进入或离开搅缸窗口。
- 下一位客人走到前柜。
- 某个要人的站有活等着，却没有人。
- 某块田今晚收工会因天气降品相，且离收工只剩 1 工时（见 `06` §5）。

推进不替玩家派工，也不改酒路和火候。要人的站没人时，该站停住，其余站继续走。

除了推进，时间不会走。组批、派工、上架、翻账册、摆家具都不耗工时。没有现实倒计时。关掉游戏，院就停在最后一次写盘的工时。

**一键收工**：等于连续推进到第 8 工时，途中不停，但交接点上的事照常结算（窗口过了没搅照样记 `stir_miss`，没人看柜的客人照样离开）。按下前弹一句确认，列出会因此错过的窗口和客人。

### 2.3 天气

天气按日决定，开坊时公布当日天气和后三日预报。预报准确。

| 天气 | 摊席 | 水田 | 发酵 | 客流 |
|---|---|---|---|---|
| 晴 | 正常 | 今日照料为浇水 | 正常 | 正常 |
| 阴 | 正常 | 今日照料为除草 | 正常 | 正常 |
| 雨 | 速度见 `04`，席收到檐下，保留进度 | 今日照料为扶秧。G4–G5 未扶则倒伏降品 | 正常 | 减少，见 `04` |
| 暑 | 速度见 `04` | 今日照料为遮阴。G3–G5 未遮则降品 | 窗口变窄，见 `04` | 正常 |

概率、首三日保底、连续雨限制见 `04` §2。天气只影响上表各项，不改蒸甑、压榨、酒窖的基础耗时。

### 2.4 周、圩日与季

- 一周 7 个酒坊日。第 6 日是圩日：客流倍率见 `04`，游客加入客人池，老周米多价低、收酒价略好。
- 一季 28 日。首发不切春夏秋冬四套地图，只用这一季把稻的复种跑通。
- 账册顶部显示「距圩日 N 日」。批购交期按酒坊日数，不看星期。

## 3. 批次与主链

### 3.1 组批

- 米进米囤时带品种、品相。
- 玩家从米囤组批：同品种、同品相才能成一批。斗数在当前等级的 `batchMin` 到 `batchMax` 之间，见 `04` §4。
- 组批时选定酒路。酒路决定后面走哪些站，见 `07` §2。选定后，在进入蒸甑之前可以改；上甑之后锁定。

### 3.2 流转

```text
米囤 → 浸缸 → 蒸甑 → 摊席 → 曲案 → 发酵房
        甜酒酿：短发酵 → 装瓶 → 后仓 / 前柜
        米酒：满发酵 → 压榨 → 酒窖 → 后仓 / 前柜
        清酒：满发酵 → 压榨 → 澄清 → 酒窖 → 后仓 / 前柜
        桂花酿：米酒路径 → 调配 → 后仓 / 前柜
```

压榨口若判定为败酿，玩家改选醋、料酒或饲料，不再进入澄清、酒窖和调配。清酒离开澄清槽时还会再判一次。见 `07` §9。

后仓满时，做完的成品留在出口站，不坏，但占着那一站，直到后仓腾出位置。

### 3.3 并行

在制批次上限见 `04`。米囤里的米不算在制。甜酒酿因为不过窖，周转快，用来赶圩日和喂街坊；坛装酒占用窖位，单价高，用来接茶客、行商和批购。

### 3.4 人手

要人的站（采收、蒸甑、曲案、压榨、调配、前柜）必须有人手在岗才走。玩家本人是「当家」，不占名额，规则见 `16` §3。人手数量见 `04` §4。

## 4. 系统边界

| 系统 | 管什么 | 不管什么 |
|---|---|---|
| 水田 `06` | 阶段、当日那一件照料、品相、倒伏、老周的米 | 酒的五味 |
| 酿造 `07` | 酒路、工站完成条件、瑕疵、败酿、成色何时加算 | 售价数字 |
| 蒸甑特写 `03` | 火候三条参数怎么显示和手感 | 判定阈值 |
| 前柜 `08` | 谁来买、为什么成交或离开、批购 | 稻怎么长 |
| 布置 `09` | 能不能放下、挡不挡路 | 风格好不好看 |
| 氛围 `13` | 布置如何变成客流和溢价；五味如何合成 | 系数 |
| 人物 `16` | 谁擅长哪一站、委托、对话 | 工资以外的数值发明 |
| 成长 `10` | 等级解锁什么 | 新公式 |

## 5. 一日结束时账上必须说清的三行

1. 田：哪块升了阶段，哪块降了品相，原因是天气还是没照料。
2. 酒：哪批出了成品或败酿，哪批还在哪一站，有没有误了搅缸。
3. 柜：卖了什么、没卖的主因、距圩日还有几天。

这三行的文案规则见 `12`。生成它们的数据必须能从当日 diff 里得到，不另掷随机。

# 灯光、水雾与酒色

版本：0.2 · 2026-10-01  
主责：一天里的光、天气里的雾、酒液颜色怎么跟状态走。它们不单独产生客流。客流只走 `13`。粒子上限见 `04` §13。

## 1. 一日的光

八个工时分成三段，见 `04` §2.1。

| 工时 | 光 | 玩家据此能认出 |
|---|---|---|
| 1–5 | 昼，软阴影，粉墙是亮的 | 稻色、饭色 |
| 6 | 傍晚，灯开始有轮廓 | 埠头的人影变长 |
| 7–8 | 入夜，纸灯亮，田上有少量萤火 | 缸沿的窗口环仍然看得见 |

入夜不把场景压成看不清工站。名牌和窗口环保持对比。

## 2. 天气

| 天气 | 光与雾 | 不做 |
|---|---|---|
| 晴 | 影清楚，没有雾片 | — |
| 阴 | 影变软，远河对比下降 | 不改工时长度 |
| 雨 | 檐下雨线，摊席空着 | 雨线不挡名牌 |
| 暑 | 地面更亮，蝉只是声音 | 不用热浪扭曲整个画面 |

倒伏和遮阴是田里的模型状态，见 `06`，不是后处理滤镜。

## 3. 水

田水、河水、浸缸水面共用一套平面：两张滚动法线，岸边略深。不做法线以外的流体。  
雨天田水线视觉上高一档，只是表现，和「今日照料是扶秧」不冲突。

## 4. 酒色

酒液是坛或瓶里的一块半透明体，颜色由酒路决定，深浅由成色分三档。档位只服务外观：低于 50、50–69、70 以上。成色数字仍以 `04` 为准。

| 酒路或去向 | 颜色 |
|---|---|
| 甜酒酿 | 乳白，略浊 |
| 米酒 | 琥珀 |
| 清酒 | 浅金，更透 |
| 桂花酿 | 琥珀里一点金点 |
| 醋 | 深褐，布盖，无封签 |
| 料酒 | 浅褐 |
| 饲料 | 不装酒液，用麻袋 |

焦糊和夹生体现在饭床上，不把整坛酒染成黑色。瑕疵靠图标。

## 5. 粒子

发酵进度过 0.3 才有气泡。窗口期内加密，加密不增加判定。入夜酒香粒子贴着前柜和窖口。数量见 `04` §13。镜头离开该站时粒子停，数据不停。

## 6. 和氛围的关系

暖光灯、植物把 `warm` 和植物计数交给 `13`。本节只规定它们亮不亮、什么时候亮。入夜纸灯即使没有 `warm` 标签也会亮，那是场景灯，不计 `lightBonus`。只有玩家摆上去、带 `warm` 的灯才计入。

# UI/UX 流程与线框

版本：0.2 · 2026-10-01  
主责：镜头、账册、蒸甑与看缸的界面、首日引导、日结三行怎么写。规则见 `02`、`03`、`07`、`08`。数字见 `04`。

## 1. 原则

- 玩家先看见院子，再看见字。账册是掀开的一页，不盖住整院。
- 能用形状说明的状态，不只靠颜色。夹生、焦糊、该搅了、倒伏，各有图标。
- 一次只问一个决定。组批时先问酒路；上架时再问标价档。
- 静音可以玩。关键音效都有图标对应，见 `18`。

## 2. 镜头

| 档 | 看到什么 | 进入方式 |
|---|---|---|
| 全院 | 田、廊、柜至少三站 | 默认；滚轮拉远 |
| 工站 | 该站锚点 | 点击工站名牌 |
| 蒸甑特写 | 饭床和三条火候 | 蒸甑有人手在岗，玩家选择亲手蒸 |
| 看缸 | 缸沿和搅缸按钮 | 窗口期内点击那口缸 |
| 账册 | 右侧半页 | Tab 或账册图标 |

全院档下，工时、天气、距圩日、文，固定在上缘。不显示成色公式。

## 3. 账册

| 页 | 内容 |
|---|---|
| 今日 | 天气与后三日、今日照料动词、在制批次、客人到达工时 |
| 米与酒 | 米囤、家曲、桂花、后仓、展位 |
| 酒谱 | 已出的酒，五味和酒名。容量见 `04` §11 |
| 人手 | 谁在哪一站，伙计是否上工 |
| 本季 | 三件自定目标，见 `10` §6 |
| 器物 | 布置入口 |

今日页的批次行只写：品种、酒路、所在站、剩余工时（向上取整）、瑕疵图标。

## 4. 蒸甑与看缸

蒸甑特写的线框：

```text
[ 饭床 ]          起火  ————●——
                 稳火  ——●————
                 收火  ———●———
[ 图标：正好 / 夹生 / 焦边 ]  [ 确认 ] [ 交给人手 ]
```

未学「火候眼」时不画目标带，预览图标仍然会在松手后更新。  
看缸不进长时间特写：缸沿亮环，按钮写「搅一下」。窗口过去后按钮消失，账册留下 `stir_miss` 图标。

## 5. 首日引导

只在第 1 日、且用开局存档时出现。每步完成即消失，不重复。

1. 点开那口已经在窗口里的缸，搅一下。开局阿禾在蒸甑，不会替玩家搅。
2. 到蒸甑，先给批 B 选酒路，再亲手蒸。按下确认才算完成。交给人手会蒸完这批，但没有亲手加成，这一步也不算完成。
3. 打开今日页，看明天的天气。
4. 把后仓的甜酒酿拖一瓶上展位。阿青开局就在前柜，街坊来了会买。
5. 收工前看日结三行。

引导不自动派工，不自动上架，不送钱。

## 6. 日结三行

收工时占屏幕下半，三行来自当日 diff，见 `02` §5。

| 行 | 句式 |
|---|---|
| 田 | 「1 号田到了灌浆。」或「2 号田因夜里的雨倒伏，品相降了一档。」 |
| 酒 | 「白糯米酒还在窖里，剩 2 工时。」或「这批误了搅缸。」 |
| 柜 | 「街坊买走一瓶甜酒酿。」或「茶客走了：柜上没有清酒。」 |

没有发生的行写「今天这里没变化」，不隐藏，避免玩家以为漏记。

## 7. 操作

| 输入 | 作用 |
|---|---|
| 左键 | 选站、选批、确认 |
| 右键 | 放下当前拖拽 |
| 滚轮 | 拉近拉远 |
| 方向键 | 蒸甑滑杆 ±0.05 |
| Esc | 退出特写且不确认；关闭账册 |
| 空格 | 推进到下一个交接点 |
| Tab | 账册 |

手柄不作为首发完成条件。输入模块仍把确认、取消、推进收成三个动作，方便以后绑定。

## 8. 可访问性

- 色弱：品相用印章，瑕疵用图标，火候结果用形状。
- 字号两档。默认档在 1080p 下正文不小于 18 像素。
- 界面不使用一闪而过的红屏表示失败。败酿用布盖和一句可选去向。

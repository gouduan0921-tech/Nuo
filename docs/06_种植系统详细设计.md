# 水田与收稻

版本：0.2 · 2026-10-01  
主责：稻怎么长、当日照料哪一件、品相怎么来、米怎么进囤。数字见 `04` §3。酒怎么用这些米见 `07`。

## 1. 设计目标

三块田要让玩家看见稻从秧到黄，并且让天气变成一件具体的事：今天扶秧，或今天遮阴。  
产量由品种决定，不由手速决定。品相由关键几天有没有做对那一件事决定。

## 2. 田

首发三块，都是水田。旱田、温室不进首发，也不进表。篇章用的野稻空位在田埂尽头，`enabled: false`，见 `11`。

### 2.1 阶段

| 阶段 | 名称 | 玩家看到 |
|---|---|---|
| 空 | 空田 | 水面 |
| G0 | 播种 | 浅浅的行 |
| G1 | 返青 | 短绿 |
| G2 | 分蘖 | 行被叶子盖住 |
| G3 | 孕穗 | 抽穗 |
| G4 | 灌浆 | 穗低头，仍绿 |
| G5 | 黄熟 | 穗黄，可割 |
| G6 | 过熟 | 穗发白，仍可割 |

每次收工，已播种的田 +1 阶。没有「停止生长直到浇水」。没照料的后果在品相和天气灾上，不在阶段上。

### 2.2 当日那一件

开坊时按天气生成当日照料，全院相同：

| 天气 | 照料 | 做了什么 |
|---|---|---|
| 晴 | 浇水 | 田埂水线升高一档（表现） |
| 阴 | 除草 | 田边草点消失 |
| 雨 | 扶秧 | 稻束被拢住。未做则 G4–G5 倒伏 |
| 暑 | 遮阴 | 田上拉出一层薄席。未做则 G3–G5 暑伤 |

玩家对一块田点一次，或水田工站有人站满 1 工时，则三块已播种的田都算完成。空田不需要照料。  
界面只出现这一件的动词，不并列浇水、施肥、除草、防虫四个按钮。施肥不单列，种子价里已经包含这一季的底肥。

### 2.3 品相

只统计**关键三日**：田处于 G2、G3、G4 的那三天，也就是收工后会进入 G3、G4、G5 的三天，是否完成当日照料。进入 G5 时品相定稿，所以 G5 当天割不吃亏。倒伏、暑伤、过熟在定稿后照样可以降档，见 `04` §3.1。  
完美、优良、普通用穗的整齐度和一枚始终在场的小印章区分，不只用颜色。

### 2.4 采收

- G5、G6 可割。割下的斗进入米囤，带品种和当时品相。
- 割完立刻空田，当日可以再播。
- 1 工时割 1 块。阿青在水田时，1 工时割 2 块。
- 收割表现是挥一下、稻束倒向田埂、扬起少量碎屑。碎屑数量用 `04` §13 的粒子预算里的装饰额度，不新开上限。判定与点击次数无关，点一次即进入工时。

## 3. 老周的米

老周不是第二套种植。他用来补：第一茬还没黄、或者玩家把米酿失败之后的空档。报价和品相见 `04` §3.2。  
米囤里同时有自种和买来的米时，组批仍要求同品种、同品相。来源记在斗上，供日结写「这批是田里的」或「这批是老周的」，不改成色公式。

## 4. 组批

玩家在米囤旁把斗拖成一批。不足下限不能上浸缸。超过上限的斗留在囤里。  
组批不消耗工时。选定酒路前，这批还不算在制。酒路写入并放入浸缸的那一刻，占用在制名额。此时不扣任何辅料：家曲在曲案开始时扣，桂花在调配站扣，见 `07` §6、§8。

## 5. 推进提醒

离收工 1 工时（学了「识天」为 2 工时，见 `04` §11），若存在「今晚会倒伏或暑伤」的田，且今日未照料，推进在这里停一次。停的是提醒，不自动照料。

## 6. 图鉴

稻种图鉴三格：白糯、香糯、紫糯。种过一次即点亮。野生稻的格子在首发不显示。  
图鉴不给属性加成。

## 7. 与酿造的接口

水田系统在米进入米囤时结束。它交出 `varietyId` 和 `grade`。  
它不交出五味。五味从出酒时才有，见 `13`。

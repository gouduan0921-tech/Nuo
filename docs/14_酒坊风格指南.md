# 酒坊风格指南

版本：0.2 · 2026-10-01  
主责：酒坊院和四套风格的视觉规则。摆放规则见 `09`。灯、雾、酒色见 `15`。哪套风格能买见 `04` 与 `10`。

## 1. 总原则

- 先认得出米、饭、缸、酒，再认风格。风格换的是灯、木、布、封签，不换地形，不换工站轮廓。
- 低面数，暖色，少高光条。酒液可以半透明，但不做真实折射广告片。
- 粉墙、水、竹是院子的底。风格层叠在底上面。

## 2. 酒坊院（全风格共用）

- 时令是夏末到秋初。稻在同一季里从绿到黄，不换雪景。
- 北田南埠，檐廊是深色木，墙是浅粉。水是灰绿，不是纯蓝。
- 材料状态的读法见 `07` §11，任何风格都要保住那些形状差。

## 3. 水乡微光 `water_glow`（首发）

| 项 | 规则 |
|---|---|
| 木 | 暖褐，檐柱略深 |
| 布 | 月白、淡青，幌子一条 |
| 陶 | 坛是深褐。开局三种封签色：朱、石青、月白，都带 `water_glow` 标签 |
| 灯 | 纸灯，入夜才明显 |
| 金属 | 少。甑沿一条铁色即可 |

首发商店只有这一套。开局 6 件都贴这个标签，见 `13` §5。

## 4. 暖窑 `warm_kiln`

木更红，灯更橙，布用赭。适合以后强调灶和窖。相邻 `water_glow`。首发不投放。

## 5. 白瓷 `porcelain_white`

墙更白，坛换成浅瓷色，布用很浅的灰青。高光只留在瓷沿。相邻 `water_glow`。首发不投放。

## 6. 夜泉 `night_spring`（篇章）

在水乡微光上加泉池的冷青边光。不全院换成黑夜。只出现在 `11` 打开之后。相邻 `water_glow`。

## 7. 跨风格禁则

- 不使用霓虹、像素字体、金属拉丝柜台。
- 不把现代商标贴上幌子。酒名是玩家写的，用同一套毛笔感标题字，正文用清晰的印刷宋黑。
- 封签颜色最多五种，见 `04` §11。颜色用来认自家的酒，不用来表示成色。

## 8. 制作顺序

先做水乡微光的院、三块田、一口缸、一架甑、前柜。暖窑和白瓷只做色板和两件替换道具的概念，不进首发包。

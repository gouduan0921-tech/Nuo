# 《糯酿》游戏总体策划案

版本：0.2 · 2026-10-01  
主责：产品定位、体验支柱、范围与成功标准。系统细则见 `02` 起各专项；所有数字见 `04`。

## 1. 一句话

在一进水乡酒坊院里，把三块田里的糯米蒸熟、下曲、看缸，酿成街坊愿意带走的一坛酒。院里各站同时在转。玩家能看出哪一缸到了该搅的时候，也知道柜上那坛为什么卖了、为什么没卖。

## 2. 定位

| 项 | 决定 |
|---|---|
| 类型 | 单人、轻度 3D 酒坊经营（水田 + 酿造链 + 小店零售 + 批购） |
| 参照体验 | 生产链的可视化与堵点排查；小店经营的定价与客群；蒸饭与看缸的短时专注 |
| 气质 | 安静、清楚、米和酒的变化看得见。低面数暖色写实，风格名「水乡微光 · 暖坛」 |
| 场地 | 一进酒坊院，约 48 × 28 米，大于一屏。北田南柜，东侧摊席，西侧酒窖 |
| 单局 | 一个酒坊日 8 工时。熟手约 15–25 分钟过完一天 |
| 中期 | 一周 7 日，每周第 6 日圩日。一季 28 日，足够种下并收完两到三茬 |
| 长线 | 酒坊 1–4 级（首发）。之后是风格、夜泉篇章与自定酒谱 |
| 平台 | 电脑端首发，键鼠操作，预留手柄 |
| 团队假设 | 小团队 + AI 辅助。内容数据驱动；美术走 Blender → GLB → Unity |
| 引擎 | Unity 6 LTS，C#。三维：Blender |

好玩和好看好于写实酒厂。它是亲手把一斗米做成有人要的酒，不是农艺考试，也不是品酒考证。

## 3. 目标用户

- 喜欢看着一处地方运转起来，并自己找出哪里堵住的人。
- 愿意为一次蒸饭或一次看缸停下来的人。
- 喜欢「今天该做什么」有理由的人：明天有雨，今天把摊席上的饭收进檐下；后天圩日，得先有甜酒酿上柜。

年龄取 18–40，作为题材尺度，不作为系统门槛。  
不作为设计前提：硬核农业模拟、真实酿酒配比、开放世界清任务、高速手操、强社交、重课金。

## 4. 体验支柱

每条支柱都要有能验收的样子，见 `26`。

1. **离屏也在干活。** 镜头在前柜时，稻照样长，缸照样发酵，窖里照样陈。挪回去看到的是结果，不是一个等着点的按钮。
2. **一眼能认站、认货。** 青稻、黄熟稻、干米、湿饭、发酵缸、甜酒酿、米酒、清酒、醋坛，靠轮廓和材质就能分开。
3. **决定少而硬，都有理由。** 玩家每天要定的事：
   - 哪块田今天照料，照料哪一件（由天气给出唯一建议）
   - 这批米走哪条酒路
   - 蒸的时候火怎么走
   - 搅缸的窗口来了做不做
   - 谁站哪一站
   - 标价放哪一档
   - 接不接老周的批购

   淘米、翻摊、日常除草由人手完成。
4. **蒸甑是亲手的一站。** 人手按默认火候蒸，能出酒。玩家亲手蒸的那批，在目标带内完成，成色更高，五味更稳。
5. **看缸是第二个短决定。** 发酵走到窗口时，搅一次就避开 `stir_miss`。错过可以继续酿，酒会更浊，也可以在压榨口改去向。
6. **卖不掉要说得出为什么。** 太贵、想要别的酒路、想要更净、柜上没有。布置只影响客流和一点溢价，不能把次酒卖成完美。
7. **可中断。** 每个工时结算后写盘。天气、客人、老周报价都由种子决定，读档不重掷。

## 5. 核心循环一览

```text
每日：看预报与老周报价 → 照料 / 收稻 → 组批 → 派工 → 各站并行
     → 亲手蒸一批、在窗口搅一缸 → 上柜定价 → 接待客人 / 交批购 → 收工三行日结
每周：为圩日备甜酒酿或桂花酿；雨天不把饭晾在露天摊上
一季：播、管、收、大批入缸、圩日售出 → 酒坊升级
长线：扩缸、添窖位、解锁品种和酒路 → 客群变化 → 酒坊的风格固定下来
```

细则见 `02`。

## 6. 商业模式

首发是完整单机，买断制。文、声望、酿艺点都在玩法内循环。泉华只服务夜泉篇章，首发不投放。广告、内购、DLC、赛季通行证的接口见 `25`，默认关闭。验收底线是：不付费也能在 28 个酒坊日内到 4 级，并且甜酒酿和至少一条坛装酒路都卖出过。

## 7. 长线内容

| 阶段 | 玩家得到什么 | 依赖 |
|---|---|---|
| 首发 | 十一站主链、天气与圩日、老周、批购、酒坊 1–4 级、水乡微光、两名常驻 | `02`–`10`、`12`、`16`、`17`、`19`–`22` |
| 第一季 | 暖窑 / 白瓷两套风格、中秋桂花活动 `act_osmanthus`、常驻旧事短篇、酒坊 5 级接口 | `14`–`16`、`23` |
| 夜泉章 | 野生稻走同一条主链，晚照短篇，一处泉院小景 | `11` |
| 可选扩展 | 酒帖分享、异步拜访、节日活动、外观包 | `23`、`24`、`25` |

首发把稻收在 3 种、酒路收在 3 条（第 4 条随 3 级开），是为了先把「种熟 → 蒸到能看懂的饭 → 酿成客人要的那一坛」打磨顺。横向加品种不改规则。

## 8. 成功标准

**首日：**

- 新玩家在第 1 个酒坊日内，对开局那缸已在发酵的酒完成一次窗口内搅缸，并亲手蒸完开局那批待蒸的米。
- 同一天里，至少还有一批在浸缸或发酵房里并行。
- 收工前，前柜至少成交一次。开局后仓备有 4 瓶甜酒酿，阿青站在前柜，见 `04` §1.1。

**首周：**

- 玩家能指出：哪一天因为天气改变了摊席或水田的做法。
- 圩日当天客流高于相邻平日，且柜上有至少一种甜酒酿或短周期酒。
- 一块田从播种走到可收，品相与这几天的照料一致。

**发布：**

- 静音、色弱模式下仍能完成首日循环。关键状态不只靠颜色：夹生、焦糊、该搅了，都有形状或图标。
- 中断后回到最近一次工时结算，不重复扣钱、不重复出酒。
- 首发包体与帧率达到 `22` 的工程门槛，并有电脑端记录。

## 9. 明确不做

- 运行时真实流体、米饭软体、稻秆物理倒伏。
- 把游戏内香、甜、酒体写成酒精度、糖度、功效或检测报告。
- 用酒给玩家加夜视、移速、战斗或经营数值。酒意只改表现，见 `13`。
- 惩罚性绝收、强制好友、付费才能完成蒸饭或发酵。
- 首发就把开放地图、黑糯、四套风格、夜泉章、联机和运营活动全部做完。

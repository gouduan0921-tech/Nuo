# 音效与音乐设计

版本：0.2 · 2026-10-01  
主责：声床、工站声、天气声、哪几处要有反馈。音乐是原创的，不引用现成曲子。

## 1. 方向

竹笛、古筝、流水、虫鸣，音量让在环境声下面。玩家要能听出缸在冒泡、雨打在檐上、收工的那一声。  
不唱词。不使用带版权的民乐录音当背景。

## 2. 音乐

| 层 | 何时 | 做法 |
|---|---|---|
| 昼 | 工时 1–5 | 笛与筝，疏 |
| 傍晚 | 工时 6 | 同一主题，少一件乐器 |
| 入夜 | 工时 7–8 | 只留低频的水和偶尔一声筝 |

层之间交叉淡入 2 秒，不切歌。蒸甑特写把音乐压低，让蒸汽声上来。圩日不换一首「欢快战曲」，只在昼层上加一点集市的远处人声。

## 3. 环境声

| 状态 | 声 |
|---|---|
| 晴、昼 | 水、稀落的鸟 |
| 阴 | 水更近，鸟少 |
| 雨 | 檐雨。摊席没有暴晒的蝉 |
| 暑 | 蝉。雨和蝉不同时 |
| 入夜 | 虫鸣、少量萤火不发声 |

环境声随镜头稍稍偏向所在区域，离屏的站不各播一遍。发酵的气泡只在镜头靠近发酵房或看缸时清晰，远处变成很低的一层。

## 4. 音效

| 事件 | 声 | 没有声时的界面 |
|---|---|---|
| 收割 | 稻束倒下，短 | 田的阶段变化 |
| 蒸饭确认 | 蒸汽一响 | 火候图标 |
| 搅缸 | 木耙碰缸沿 | 窗口环灭掉 |
| 误了窗口 | 很轻的一声，不刺耳 | `stir_miss` 图标 |
| 装坛 | 坛口一扣 | 成品进后仓 |
| 成交 | 铜钱一声 | 日结会再写 |
| 客人离开 | 脚步远去 | 离开原因 |
| 收工 | 一记木鱼似的敲击 | 三行日结 |

败酿不播失败音。弹出的是三选一。

## 5. 实现

- 总音量、音乐、音效三档，都可归零。
- 同一事件 0.2 秒内不叠两声。
- 音效文件 `sfx_`，音乐 `bgm_`，见 `17`。

## 6. 不做

- 语音配音。对话只出字。
- 用音乐提示「这坛是极品」。极品看形状和酒谱。
- 循环一段带歌词的流行歌。

# 配置表结构

版本：0.2 · 2026-10-01  
主责：表有哪些、字段叫什么、ID 怎么写。字段里的数字必须与 `04` 一致，表里不发明第二套价格。运行时对象见 `21`。

## 1. 约定

- 路径：`content/`。UTF-8 JSON。
- ID：小写英文与下划线，前缀表达种类，如 `var_white`、`wine_rice`、`guest_tea`。
- 枚举用英文码，界面文案用 `name`。
- 耗时单位是工时，可以是小数。价格单位是文。
- 首发关闭的行照样进表，`enabled: false`。加载时跳过，存档里若出现则拒绝读入，见 `21`。

## 3. 字段

### stations.json

```json
{
  "id": "station_ferment",
  "name": "发酵房",
  "mode": "timer",
  "hours": { "wine_sweet": 3, "default": 6 },
  "needsWorker": false,
  "earlyLeave": "forbid"
}
```

`mode`：`timer` 或 `worker`。`earlyLeave`：`forbid`、`mix_uneven`、`rush_clear`。

### varieties.json

`id`，`name`，`seedPrice`，`yield`，`varietyK`，`targetRise`，`targetHold`，`targetRest`，`enabled`。

### wine_paths.json

`id`，`name`，`stations`（有序工站 ID 数组），`perDou`，`unit`（`jar` 或 `bottle`），`basePrice`，`pathBonus`，`unlockLevel`，`koji`，`adjunct`，`enabled`。

甜酒酿的 `stations` 不含 `station_press`。桂花酿在米酒站序之后加 `station_blend`。

### workshop_levels.json

`level`，`cost`，`renown`，`trafficBase`，`batchMax`，`batchMin`，`activeBatches`，`workers`，`granary`，`cellarSlots`（按批计），`counterSlots`，`storeSlots`，以及各站容量。名字与 `04` §4、§10 的列一一对应。

### guests.json

`id`，`name`，`weight`，`fairWeight`，`pathIds`，`minQuality`，`tiers`，`taste`（在意的一味），`enabled`。

### taste_mods.json

`source`（品种、酒路、`long_age`、`excellent`、瑕疵 ID），`xiang`，`tian`，`chun`，`jing`，`yun`。

### furniture.json

`id`，`name`，`zoneIds`，`styleIds`，`atmosphere`，`footprint`（格），`price`，`unlockLevel`，`blocksPath`（必须为 false 的物件才会被校验通过）。

### npcs.json

`id`，`name`，`giftTaste`（`xiang` / `tian` / `chun` / `jing` / `yun`），`startAffinity`，`enabled`。首发常驻不填耗时倍率。专长规则见 `16` §3，好感数字见 `04` §11.1。

### orders.json

批购：`id`，`levelMin`，`levelMax`，`pathIds`，`count`，`dueDays`，`deposit`，`minQuality`，`enabled`。  
委托：`id`，`npcId`，`pathId`，`minQuality`，`after`（前置委托或条件），`rewardRenown`，`rewardCraft`，`enabled`。数字见 `04` §10.5，表是落地处。

### products_visual.json

瓶坛：`id`，`unit`（`jar` / `bottle`），`mesh`，`unlock`。  
封签：`id`，`name`，`color`，`styleId`，`unlock`（`start`、`skill_seal`、`level_3`、`activity`）。开局三种封签都是 `water_glow`，`13` §4 的 `styleMatch` 从这里取。

### activities.json

`id`，`enabled`，`modifiers`。允许的键只有 `23` 列出的白名单。

## 4. 入库校验

加载失败就停在标题画面，不进半套表。

- 每个 ID 唯一。
- `wine_paths.stations` 里的每个 ID 都存在于 `stations`。
- 甜酒酿不得包含压榨、澄清、酒窖。
- 清酒必须包含澄清。桂花酿必须包含调配，且 `unlockLevel >= 3`。
- `enabled: false` 的品种不得出现在 `start_state`。
- `start_state` 的批 A 进度必须落在晴天搅缸窗口内；开局人手不得站在发酵房（否则阿禾会替玩家搅掉首日引导的第一步）。
- 升级花费、声望门槛、种子价、基础单价、客流基数、批购表与 `04` 不一致时，校验失败。
- 家具 `blocksPath == true` 直接失败。通路不由美术单件决定。

# 美术资源与命名规范

版本：0.2 · 2026-10-01  
主责：命名、导入检查、面数和贴图上限的执行。上限数字见 `04` §13。风格见 `14`，状态读法见 `07` §11。

## 1. 命名

小写英文与下划线。前缀：

| 前缀 | 用途 |
|---|---|
| `mdl_` | 网格 |
| `tex_` | 贴图 |
| `mat_` | 材质 |
| `anim_` | 动画 |
| `sfx_` | 音效 |
| `bgm_` | 音乐 |

例子：`mdl_vat_ferment`、`mdl_rice_bed`、`mdl_jar_rice`、`tex_seal_zhu`、`anim_npc_he_stir`。  
变体放在名字末尾：`mdl_rice_bed_hard`、`mdl_rice_bed_gloss`、`mdl_rice_bed_scorch`。

禁止用中文文件名、空格、以及「最终」「最新」「new」。

## 2. 预算

三角面和贴图边长不得超过 `04` §13。院景图集一张 2048，角色各自一张 1024。蒸甑形态键只在 `mdl_rice_bed` 上，不在静态三档上再叠键。

稻用实例。每块田 80 丛，不把每一株做成独立网格。

## 3. 必须能分开的状态

这些要做成不同网格或同一网格的明显形态，不能只换一个几乎看不出的色值：

- G0 到 G6 的稻
- 湿米、夹生饭、正好的饭、焦边
- 发酵缸的平静与冒泡
- 窗口环开 / 关
- 甜酒酿、米酒、清酒、桂花酿、醋、料酒、饲料
- 短陈一道绳、长陈两道绳

## 4. 导出

- Blender 单位米，应用缩放（Apply Scale）。Blender 内保持默认 Z 向上，导出 glTF 时勾选 +Y Up。
- 导出 GLB。贴图不嵌在模型里的第二份大图；由图集引用。
- 轴和锚点：工站锚点在地面，角色脚底在地面，酒坛底在地面。
- 导入 Unity 后检查：无相机、无灯、无默认材质球。

## 5. 角色

阿禾、阿青、老周各一套。晚照的模型不进首发包。  
玩家两种体型共用骨架。衣服三色是材质参数，不是三套网格。

## 6. 检查清单

入库前：命名、面数、贴图尺寸、状态是否可辨、GLB 无多余节点。不过检的文件不进 `game/NuoBrew` 的运行时目录。

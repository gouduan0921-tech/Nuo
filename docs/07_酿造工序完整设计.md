# 酿造工序

版本：0.2 · 2026-10-01  
主责：一批酒经过哪些站、什么时候记瑕疵、什么时候算成色、败酿怎么分叉。耗时、容量、加减值见 `04`。蒸甑特写见 `03`。

## 1. 一批身上有什么

从组批起，批次固定这些字段，中途只按本文件的规则改：

- `varietyId`，`grade`，`dou`
- `pathId`
- `stationId`，`hoursLeft`
- `defects[]`
- `handmade`（蒸甑是否玩家确认）
- `stirred`（是否在窗口内搅过）
- `longAge`（下窖时是否勾选长陈）
- `name`，`sealId`，`bottleId`（出成品时写入，之前可空）

斗在一批里不可拆。出酒时按 `04` §6 把整批换成若干瓶或坛，这些成品共享同一组成色和五味。

## 2. 酒路

| 酒路 | 站序 |
|---|---|
| 甜酒酿 | 浸缸 → 蒸甑 → 摊席 → 曲案 → 发酵房 → 装瓶 |
| 米酒 | 浸缸 → 蒸甑 → 摊席 → 曲案 → 发酵房 → 压榨 → 酒窖 → 装坛 |
| 清酒 | 在米酒的压榨之后、酒窖之前插入澄清 |
| 桂花酿 | 米酒站序，酒窖之后、装坛之前插入调配 |

未解锁的酒路不能选。1 级只有甜酒酿和米酒。

## 3. 浸缸

计时。淘米和浸泡并在这一站，不单做淘米小游戏。时间走完才能上甑。不能提前离开。

## 4. 蒸甑

要人。工时见 `04`。

- 玩家进入特写：按 `03` 写瑕疵和 `handmade`。
- 人手：参数取品种目标中心，无蒸饭瑕疵，`handmade = false`。
- 亲手蒸也要蒸甑上有人手在岗：人手烧火，当家掌火候。
- 没人时，浸缸已完成的批停在甑前，不坏。

火候不改变这一站的工时。

## 5. 摊席

计时，速度看天气。雨天席在檐下，进度保留，只是变慢。  
玩家可以把一批提前送去曲案，立即记 `mix_uneven`，并开始曲案。这是唯一允许的「没凉透就拌」。

## 6. 曲案

要人。开始时扣 1 份家曲。家曲不足则不能开始，批停在曲案前，不坏。  
桂花不在这里扣。桂花在调配站扣。  
拌曲由人手做。首发只有家曲一种，玩家不用选。没有第二套搅拌条，也没有亲手拌曲的加成。

## 7. 发酵房

计时。甜酒酿 3 工时，其他酒路 6 工时。

窗口：进度 0.50 为中心，宽度见 `04` §2.3。进入窗口时，若玩家打开了推进，时间停一次。

- 窗口内有人搅缸，或玩家在窗口内点搅：`stirred = true`。
- 窗口结束时 `stirred` 仍为 false：记 `stir_miss`。缸继续走完，不销毁。
- 窗口外点搅：无效果，不额外记瑕疵。

暑天窗口更窄，总时长不变。缸的气泡在进度 0.3 之后出现，窗口期内气泡更密，密的是表现，判定只看有没有在窗口内搅过。

技能「早看缸」只把起点提前，见 `04` §11。

## 8. 压榨、澄清、酒窖、调配

- 压榨要人。开始前先做败酿判定，见 §9。通过则出酒液，进入下一站。
- 澄清只属于清酒。提前离开记 `rush_clear`。
- 下窖时选择短陈或长陈。长陈把该批 `hoursLeft` 设为 8，并标记 `longAge`。窖位按批计。窖位不足就不能下窖，批停在窖口，不坏。
- 调配要人，扣 1 份桂花。桂花不足则停在调配案。没有「不加桂花也叫桂花酿」。

装瓶或装坛时，玩家写酒名（1–8 个字，默认为酒路名），选已解锁的瓶型和封签色。不选则用默认瓶和默认封签。名字和封签不进成色；封签的风格会进 `moodK`，见 `13` §4。

后仓满时，成品留在出口站（发酵房的缸、窖位、澄清槽、调配案），不坏，但占着那一站，不能接下一批。

## 9. 成色与败酿

离开发酵房时先结算成色，公式见 `04` §7。之后若再获得 `rush_clear`，成色按瑕疵数重算一次。

败酿线：`quality < 36` 或瑕疵种类 ≥ 3。

- 有压榨的酒路：在压榨开始时拦截，玩家三选一：醋、料酒、饲料。
- 清酒：离开澄清槽时再判一次。`rush_clear` 是唯一会在压榨之后新增的瑕疵，所以只需要这一个第二判定点。
- 甜酒酿：在发酵结束时拦截，同样三选一。
- 选定后移除酒路，成品记为败酿类型，不再进入后续酒站。

败酿可以上柜，但首发没有客人以败酿为目标，等于卖不掉，除非以后的活动显式允许。饲料可以留着抵开销。

## 10. 五味何时计算

成品装瓶装坛时算一次，写入成品，之后不随天气改变。五味结构见 `13`，加减见 `04` §8。  
酒谱展示五味，前柜匹配用同一份数据。

## 11. 可见状态

| 状态 | 形状 |
|---|---|
| 浸缸中 | 米在水面下，水面有浅纹 |
| 待蒸 | 甑空，旁边一筐湿米 |
| 夹生饭 | 饭床颗粒分开 |
| 正好的饭 | 饭床合拢、一块高光 |
| 焦边 | 饭床边缘缺一块亮，呈硬边 |
| 发酵中 | 缸盖缝有气泡 |
| 该搅了 | 缸沿一圈亮木环，并有固定图标 |
| 短陈 / 长陈 | 坛绳一道 / 两道 |
| 败酿 | 坛嘴加布盖，不贴酒封签 |

## 12. 现实对照

| 游戏里的站 | 参照的手工关系 | 游戏里的压缩 |
|---|---|---|
| 浸缸 | 淘净再浸泡 | 合并，不单做淘米 |
| 蒸甑 | 蒸到饭熟、不糊 | 三条火候，1 工时 |
| 摊席 | 摊凉到能拌曲 | 1 工时，可提前并记瑕疵 |
| 曲案 | 拌曲 | 只选已有的曲，首发不培养菌种 |
| 发酵房 | 发酵中途开耙、搅动 | 一个窗口，错过记瑕疵 |
| 压榨 | 酒糟分离 | 要人，2 工时 |
| 澄清、酒窖 | 静置与坛装存放 | 数工时，不是数月 |
| 调配 | 成品后加桂花一类辅料 | 只在桂花酿 |

文案不写酒精度、糖化酶、温度摄氏度。温度在界面里是「缸是温的」「缸太热」，暑天用窗口变窄来表示，不出现数字温度。

## 13. 不做

- 酒曲杂交、孢子采集、菌种小游戏。家曲是每日拌曲后回一份的消耗品。
- 逐小时温度曲线经营。窗口只有一段。
- 失败即倒掉。
- 在缸里捏饭或在蒸甑里调配桂花。

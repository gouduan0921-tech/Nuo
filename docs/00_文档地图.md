## 1. 一段话读懂 0.1

玩家在江南水乡的一进酒坊院里，种三块糯稻田，把米走成酒。米从水田来，不够时才向酒商老周买。一批米依次走浸缸、蒸甑、摊席、曲案、发酵房，再按酒路进入压榨、澄清、酒窖或调配，最后上前柜卖给街坊。院里各站同时运转。玩家要做的是看天、照料稻、决定这批酿成什么、在蒸甑上亲手控一次火、在发酵窗口里搅一次缸、定价卖给谁。

## 3. 权威来源与冲突处理

同一件事只在一处定义。冲突时先改主责文档，再改引用方，下游不得另写规则。

| 事项 | 主责 | 引用方只能 |
|---|---|---|
| 做什么、不做什么、体验承诺 | `01` | 引用 |
| 时间、天气、周节奏、批次流转、系统边界 | `02` | 引用 |
| 任何数字（耗时、容量、价格、概率、门槛） | `04` | 写「见 `04` §x」，示例须与 `04` 一致 |
| 五味与氛围的公式结构 | `13`（系数在 `04`） | 引用 |
| 工站规则、酒路、瑕疵、败酿何时成立 | `07` | 引用 |
| 蒸甑特写怎么画、参数怎么映射到米饭 | `03` | 引用；判定阈值仍以 `04` 为准 |
| 客人、匹配、成交、批购规则 | `08` | 引用 |
| 表字段与 ID | `05`；运行时结构 `21` | 引用 |
| 布置与通路 `09`；风格 `14`；灯雾酒色 `15` | 各自 | 引用 |
| 人物、专长、对话、派工名额（含玩家本人） | `16` | 引用 |
| 是否可发布 `26`；开发顺序 `27` | 各自 | 不覆盖 `01`–`25` |

改 `04` 的任何数字后，先同步 `tools/econ_handcalc.py` 顶部常量并运行 `python3 tools/econ_handcalc.py`，把结果写回 `04` §12。蒙特卡洛模拟器落地后改为 `python3 tools/sim_economy.py --runs 300 --days 28`。

## 4. 统一术语

| 词 | 含义 |
|---|---|
| 酒坊院 | 首发唯一场地。北田南柜，东侧摊席，西侧酒窖。各站同时运转，不切场景 |
| 当家 | 玩家本人。不占派工名额，不能代替人手站柜、割稻、压榨。能亲手蒸（蒸甑须有人手在岗）、在窗口内搅缸、照料水田。见 `16` §3 |
| 人手 | 阿禾、阿青，3 级起加伙计。站在要人的工站上才能干活 |
| 工站 | 院里的一处活。见下方 ID 表 |
| 酒坊日 | 一天的账本。开坊到收工 8 个工时。不绑定现实时钟 |
| 工时 | 院内节拍。所有耗时按工时结算，镜头不在也照样扣。时间只在玩家按「推进」时走 |
| 周 | 7 个酒坊日。第 6 日是**圩日** |
| 季 | 28 个酒坊日。首发只跑一季夏秋，用来完成两到三茬稻 |
| 天气 | `sun` 晴、`cloud` 阴、`rain` 雨、`heat` 暑。账册提前预报 3 天 |
| 斗 | 一份糯米，是原料和在制米的计数单位 |
| 坛 / 瓶 | 成品容器。甜酒酿出瓶，其余酒路出坛。出数见 `04` §6 |
| 窖位 | 酒窖容量，按批计：一批不论几坛只占 1 个窖位 |
| 后仓 / 展位 | 后仓存成品，客人看不见；展位在前柜上，客人只从展位买 |
| 批次 | 同一品种、同一品相、一起流转的若干斗 |
| 米囤 | 浸缸入口的原料堆。收来和买来的米先放这里，再由玩家组批 |
| 品相 | `normal` 普通 / `good` 优良 / `excellent` 完美。只来自稻本身。`legend` 传说留给篇章，首发不出现 |
| 关键三日 | 田处于 G2、G3、G4 的那三天。这三天照料了几天，决定品相 |
| 酒路 | `sweet` 甜酒酿、`rice` 米酒、`clear` 清酒、`osmanthus` 桂花酿。酒路是产品，不是品质 |
| 五味 | 香、甜、醇、净、韵。由品种、酒路和瑕疵推出来，供客人匹配和酒谱展示 |
| 瑕疵 | `steam_hard` 夹生、`steam_scorch` 焦糊、`mix_uneven` 拌不匀、`stir_miss` 误了搅缸、`rush_clear` 澄清不足 |
| 败酿 | 瑕疵过多或成色过低时，在压榨口改成醋、料酒或饲料。不销毁 |
| 成色 | 0–100。决定能不能走正酒、以及基础售价 |
| 标价档 | 让利 / 平价 / 讲究 |
| 批购 | 老周按交期收的批量酒。收定金 |
| 常驻委托 | 阿禾、阿青给的小委托，带短对话 |
| 文 / 声望 / 酿艺点 / 泉华 | 软通货 / 0–100 声望 / 亲手蒸甑与看缸所得 / 篇章资源（首发不投放） |
| 酒意 | 自品后的当日表现标签。不进经济和工时 |
| G0–G6 | 水田阶段。G5 黄熟可割，G6 过熟 |
| 封签 | 瓶坛上的颜色与酒名。是展示，不是品质 |

工站 ID：`station_paddy` 水田、`station_soak` 浸缸、`station_steam` 蒸甑、`station_cool` 摊席、`station_mix` 曲案、`station_ferment` 发酵房、`station_press` 压榨、`station_clear` 澄清槽、`station_cellar` 酒窖、`station_blend` 调配案、`station_counter` 前柜。

## 5. 现实与虚构

- 工序顺序参照江南糯米酒的手工关系：淘浸、蒸饭、摊凉、拌曲、入缸、发酵中搅动、压榨、澄清、坛装陈放，需要时再加桂花一类辅料。现实对照表见 `07` §12。
- 时间是压缩的。现实里一季糯稻和一坛酒的发酵、陈放都以天和月计。游戏把它们压进酒坊日和工时。文案不写现实天数，也不写真实酒精度。
- 五味和成色只在游戏里成立。不写饮用功效、保健、解酒或真实检测报告。
- 败酿改成醋、料酒、饲料，是游戏里的去向，不写成食品工艺教程。
- 夜泉、泉华、野生古老稻、酒仙晚照是虚构篇章，走同一条主链。

## 6. 首发范围

**首发可玩：**

- 一进酒坊院，十一个工站
- 三块水田，加上老周卖米
- 天气、周节奏与圩日；工时内含傍晚和入夜
- 白糯、香糯、紫糯
- 家曲；桂花在酒坊 3 级开放（只在调配站加，没有单独的桂花曲）
- 四条酒路里先开放甜酒酿、米酒、清酒
- 败酿三去向
- 前柜零售与老周批购
- 水乡微光风格
- 酒坊 1–4 级
- 两名常驻（阿禾、阿青）、酒商老周
- 两种瓶坛外形、三种封签色、玩家自定酒名

**首发不做：**

- 开放山水、独立探索关卡、解谜副本
- 实时流体、软体米饭、物理倒伏模拟
- 战斗、夜视、加速等属性酒劲
- 自由雕刻酒瓶
- 公会、排行榜、玩家市场
- 实时联机与强制好友
- 付费跳过任何工序
- 惩罚性绝收（倒伏只降品相，田还在）

**预留配置、首发关闭：** 夜泉篇章、黑糯与野生稻、另外三套风格、节日活动、异步拜访、支付与外观包。

# 蒸甑火候技术实现方案

版本：0.2 · 2026-10-01  
主责：蒸饭特写里的米饭怎么在 Unity 里实现。工序与成色以 `07` 为准，命名以 `17` 为准，目标带、容差和亲手加成以 `04` §7 为准。

## 1. 目标与范围

浸缸结束的米才会进蒸甑。玩家亲手蒸一批时进入特写：

1. 看到这批的品种和目标火候带。
2. 调三个连续参数，或在一条火候曲线上拖三个把手。
3. 确认。预览立刻显示这锅饭是夹生、正好还是焦边。

整批共用这一组参数。首发用**三条火候参数 + 米饭形态键**。自由雕塑饭粒不做。

人手蒸这批时不进特写，直接写入该品种的默认参数。默认参数落在目标带内，没有瑕疵，也没有亲手加成。

院里同时有多批米和酒。形态键只在特写的这一甑上播放。田里、缸里、柜上一律用静态体。

## 2. 参数含义

三条参数取值都是 0–1。

| 参数 | 玩家看到的名字 | 含义 | 偏小 | 偏大 |
|---|---|---|---|---|
| rise | 起火 | 蒸汽上来的急缓 | 饭心热得慢，夹生 | 外层先焦 |
| hold | 稳火 | 中段维持的长短 | 心没透，夹生 | 水汽抽干，焦糊 |
| rest | 收火 | 停火后焖的长短 | 表面回潮，发黏 | 余热把边烤焦 |

品种的目标中心 `targetRise / targetHold / targetRest` 在 `varieties.json`，具体数字见 `04` §5。容差带外才记瑕疵：

| 出带 | 记 |
|---|---|
| 起火或稳火低于目标带 | `steam_hard` |
| 起火、稳火或收火高于目标带 | `steam_scorch` |
| 收火低于目标带 | 不记瑕疵，但这批算出带 |
| 同时触发夹生和焦糊 | 两条都记 |

判定只看是否出带，不在带内再分高低分。三条都在带内、且由玩家确认，才记 `handmade = true`。出带的亲手批 `handmade = false`，酿艺点按 `04` §11 记 +1。

## 3. 技术选型

| 方案 | 结论 | 原因 |
|---|---|---|
| 形态键 Morph Target | 首发采用 | Blender 可导出，Unity glTF 导入支持。预设稳定，面数可控 |
| 三条滑杆驱动权重 | 首发采用 | 玩家能预判，方便做色弱下的形状差 |
| 运行时软体 / 流体蒸汽 | 不做 | 结果不稳定，同屏多批次负担不起 |
| 逐粒模拟 | 不做 | 和「看一甑」的读法无关 |

- 基线网格 `mdl_rice_bed`，1.0k–1.6k 三角面。
- 三组形态键：`key_hard` 散硬、`key_gloss` 软亮、`key_scorch` 焦边。
- 蒸汽用一张循环的半透明片和少量粒子，粒子数量见 `04` §13，不参与判定。

## 4. 组件

```text
SteamSession       一次特写的会话
  SteamMeshView    显示饭床与形态键权重
  SteamCurve       起火 / 稳火 / 收火
  SteamInput       键鼠：拖把手、方向键 ±0.05、滚轮缩放、Esc 取消回到默认
  SteamPreview     带内、夹生、焦糊的文字和图标
  SteamBaker       确认后写回批次并退出特写
```

```csharp
public sealed class SteamDraft {
    public string BatchId;
    public float Rise;   // 0–1
    public float Hold;
    public float Rest;
}
```

领域层根据草稿和品种目标带算出瑕疵与形态键权重。视图层只应用权重。领域层程序集不引用 `UnityEngine`。

## 5. 权重

```text
hard   = clamp(bandDistance(hold, lowSide) + bandDistance(rise, lowSide), 0, 1)
scorch = clamp(bandDistance(hold, highSide) + bandDistance(rise, highSide) + bandDistance(rest, highSide), 0, 1)
gloss  = clamp(1 - hard - scorch, 0, 1) × (1 - 0.5 × bandDistance(rest, lowSide))
```

`bandDistance` 在目标带内为 0，出带后按超出量线性升到 1。带的半宽见 `04` §7。  
夹生时饭床保持颗粒缝隙；正好时缝隙合上、表面有一块高光；焦糊时边缘形态键压过高光；收火偏低时高光变暗、表面发黏，但缝隙仍合上。色弱玩家靠缝隙和图标区分，不靠金黄和焦黄。

## 6. 交互

- 只有蒸甑上有人手在岗时才能进特写：人手烧火，当家掌火候，见 `16` §3。
- 进入特写时时间暂停。暂停不算工时。退出后从进入前的工时继续。
- 未确认就退出：这批仍停在蒸甑，不消耗工时。
- 确认：写入参数、瑕疵和 `handmade`，蒸甑工时开始倒计时。倒计时长度不因火候好坏改变，见 `04` §4。
- 手柄：左摇杆选把手，右摇杆改值。首发可以只做键鼠，但输入模块把指针和摇杆都收成同一份 `SteamDraft`。

## 7. 性能

- 全院同时只允许 1 个蒸甑特写。
- 饭床形态键不在院景里播放。院景用三档静态体：`rice_hard`、`rice_gloss`、`rice_scorch`，由烘焙结果选一档。
- 蒸汽粒子上限见 `04` §13。镜头离开灶棚时粒子停，数据不停。

## 8. Blender 导出

- 单位米，应用缩放（Apply Scale）。Blender 内保持默认 Z 向上，导出 glTF 时勾选 +Y Up，由导出器转成 glTF 的 Y 向上。
- 形态键必须在同一拓扑上。
- 导出 GLB，不嵌贴图图集以外的大纹理。贴图预算见 `17`。
- 预览相机机位固定，供酒谱缩略图以后复用；首发缩略图可以是图标，不是实时截图。

# 多平台发布与适配

版本：0.2 · 2026-10-01  
主责：首发在哪、移植时什么不能改。帧率和分辨率见 `04` §14。操作见 `12` §7。

## 1. 首发

电脑端。Windows 与 macOS 都要能完成 `26` 的首日流程，发布记录至少留一台机器的帧率。键鼠是完成条件。手柄映射可以不做完。

分辨率目标 1920×1080，窗口可缩小，账册在 1280×720 下仍能读完今日页。字号见 `12` §8。

## 2. 帧率

院景和蒸甑特写的目标都是 60。掉到 45 以下超过 3 秒，且发生在空闲张望时，记为发布缺陷。粒子和稻丛先降到 `04` §13 的上限之内，不改玩法耗时。

## 3. 以后的端

| 端 | 0.1 的要求 |
|---|---|
| 移动端 | 不作为完成条件。触控要能表达确认、取消、推进。界面另做一版，规则不动 |
| 主机 | 不作为完成条件。手柄动作与 `12` 的三个抽象动作对齐 |
| 云存档 | 接口留在存档层之外。0.1 只写本地。同步时以当前 schema 整份上传，不合并字段 |

移植时禁止为了小屏删掉搅缸窗口或把八个工时改成现实倒计时。

## 4. 包体

未实测前不写死兆字节。首发包排除：晚照、野生稻、暖窑与白瓷的模型、活动配置的启用开关。排除方式是不加载 `enabled: false` 的资源，不是把规则删掉。

## 5. 发布门

同时满足才叫 0.1 可发布：

- `26` 的发布门用例通过。
- 支付、活动、拜访的开关在默认配置里为关。
- 一台电脑上的院景帧率记录达到 §2。
- 存档从第 1 日搅缸写盘后强退，再进仍是搅过的那一缸。

## 6. 语言与输入法

界面文案是简体中文。酒名输入允许 1–8 个字，超出不让确认。不在酒名里执行任何富文本。

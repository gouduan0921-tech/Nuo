## Overview

设计依据是糯酿 0.2 的玩法与材料规定、实际浏览的三条 Pinterest 参考，以及粥霸天现有界面。参考观察得到的是构图与层级；下列色值和尺寸是为糯酿主动制定的规格，不是从参考图片精确反推。系统字体在不同机器上的笔形会略有差别。

世界负责体积、光和材料，界面负责清楚的决定。常驻提醒控制在三件以内，状态贴着具体工位，低频功能收进账册。夜景仍能辨认田、米、饭和酒。

### Text Colors

主文字 `#363A30`；辅助文字 `#696D5C`；深场景上的反白 `#F5EFD9`。关键信息不压低到浅灰。小窗口隐藏“声望 / 酿艺点”的辅助标签时保留各自图标及可读取的名称。

### Semantic Colors

正常状态使用 `#DDE3CC` 底与主墨色；提醒用 `#D4B674` 边；瑕疵用 `#EDD8BC` 底与 `#7D422B` 字；禁放家具需明确轮廓和文字，不能仅以红绿判断。封签色为朱、石青、月白，不承担品相或成色分级。

### Gradients And Special Effects

按钮顶面亮、底面暗；暖纸只用轻微斜向渐变。全院上缘、下缘与右侧覆盖浅灰青遮光层帮助读字。景深只模糊特写周边，不模糊正在看的饭或缸。没有玻璃面板、霓虹、满屏光晕或持续飘金币。

### Typography Rules

一段说明只讲一件事，状态名用口语。长解释进账册，不盖住院子。成色与五味数字区分明确；不显示经营公式、匹配分、真实酒精度或现实温度。

## Layout And Spacing

### Spacing System

基准 4px；常用 8 / 12 / 16 / 20 / 24 / 28 / 32。面板边距 24–28，提醒卡 18–21，账页分组间距 25。场景边缘安全距 24–38。

### Grid And Containers

1920×1080 是主要观感目标，1280×720 是最小电脑阅读检查。右侧提醒宽 255–310；账册宽 445–510。工位操作面板宽 590–720，底部留出 100–125。账册超过可见范围时内部滚动，标题与六页导航留在上方。

全院名牌随真实工位锚点定位，不能在窗口改变后飘到不对应的道具上。样板中的百分比定位服务静态概念图，正式实现须由三维坐标投到画面。

窄屏仅为看方案的后备排布：画面在上，操作和提醒在下。首发平台仍为电脑，不据此宣称完成手机游戏适配。

### Whitespace Pattern

右侧三张卡之间 12–19；不要把所有工位都变成常驻大卡。主体场景占中部约七成，材料细节主要集中在当前甑或缸。重复状态不另开弹窗。

### Special Shapes

工位牌采用圆角长方形配小圆印；品相采用方印。除印章和编号外少用圆形。米白瓷片、深木和暖纸的形状保持统一，不做每屏一套异形按钮。

## Shadows And Depth

- 主按钮：4px 实体底边，顶部一条浅内高光；按下下沉 3px。
- 瓷片导航：5px 砂色底边 + 柔和投影；选中换青釉材料。
- 工位牌：4px 底边、约 8px / 18px 的软投影；需要关注时外圈加 1px 铜金细线。
- 账册与操作面板：7px 砂色底边、约 20px / 45px 的软暗影。
- 日结：与账册同材料，后景轻暗、轻模糊；不使用金属厚框。

立体阴影不承担可点击提示；同时保留按钮名称、轮廓和聚焦状态。

## Component Styles

### Buttons

| 类型 | 表面 / 字 | 圆角 / 尺寸 | 状态 |
| --- | --- | --- | --- |
| 主按钮 | 青釉渐变、米白字 | 11px，至少 48px 高 | 按下沉 3px，禁止操作时保留文字 |
| 木操作 | 暖木渐变、米白字 | 同主按钮 | 用于搅缸、交给人手 |
| 瓷次按钮 | 米白渐变、深墨字 | 同主按钮 | 返回、查看、改酒路、保存 |
| 外围安静按钮 | 深青半透明、米白字、细浅边 | 同主按钮 | 收工；避免抢推进的主次 |
| 纯图标 | 米白瓷片 + 单色线图 | 36–44px | 必须有可读取的名称 |

聚焦外圈 3px 铜金，外扩 4px。鼠标悬停可以轻亮，不放大跳动。正式重要触控按钮仍需至少 44px 可点区域，虽触控不作首发完成条件。

### Cards

提醒卡 16px 圆角，暖纸面、深墨标题、青色次行；内距 18–21。紧急卡以静态外圈 + 图标 + 动词表示。三张卡主题固定为窗口、待处理批、前柜；正式后续按真实事项取前三件。

### Navigation

左侧厚瓷入口，74×80，间隔 19；1280 下 65×70。账册六页用 16px 字和短标签，当前页青釉底与米白字，并提供当前页语义。不要增加领奖、广告、充值、好友和运营入口。

### Inputs

火候滑杆为细竹色轨、厚瓷滑块；标签、数字、结果文字同时出现。三条目标带只在火候眼已学时出现，未学也不隐藏结果预览。人手选择框米白底、砂色 1px 边、8px 圆角，明确标出准备去的站与生效时点。酒名输入在正式接入时限制 1–8 字，不能截断后悄悄保存。

### Tags And Badges

品相方印；普通 / 优良 / 完美均有文字。窗口状态用木环与“该搅了”；已搅用圆记号；夹生用菱形、焦糊用硬块、回黏用波纹、误了搅缸用固定瑕疵图标。颜色只加强含义。

### Additional Components

五味采用五条水平短条，0–100 对应长度，标签与数字一起读。收工三行使用同宽小纸条，田 / 酒 / 柜列对齐；金额栏三列分别收入 / 开销 / 余钱。长列表有分隔线，不需要每行另包卡片。后仓 / 展位 / 批购预留状态明确分开。

## Do's And Don'ts

- **Do**: 让米、饭、缸、酒通过轮廓和材质区分；可操作状态再配简短文字。
- **Do**: 工时只在推进时变化，先问酒路，再问火候，上柜时再问标价。
- **Do**: 普通状态保持安静，只让正在需要决定的站出现强调。
- **Do**: 相同视觉语法用于天气、瑕疵、等人手、等材料与后仓满。
- **Don't**: 用封签颜色表示品质，用满屏金币表示成交，用红屏表示败酿。
- **Don't**: 把所有工位面板一起展开，或用小字压缩完整账册。
- **Don't**: 添加霓虹、现代钢制流水线、真实流体或大量闪亮粒子。
- **Don't**: 把篇章、其他风格、社交和支付的预留内容当成首发菜单。

## Notes

本套静态场景材质细节比低面数运行模型丰富；正式制作应保住轮廓、明暗与操作清晰度，并按 `17` 控面数和贴图。单图的灯色预览不等于已经做出昼夜灯光、天气或三套装修。浏览器样板的流畅程度不能作为 Unity 正式院景的帧率证据。

# 糯酿界面样板 · 检查记录

日期：2026-10-01。检查对象是独立界面样板，不是 Unity 正式游戏。

## 实际打开与点击

使用本机 Chrome 打开分文件样板及最终单文件样板，实际执行了以下流程：

1. 全院进入看缸，点击“搅一下”。酿艺点从 0 到 1，按钮变为不可再操作的“已搅过”。
2. 进入蒸甑，选择米酒。起火、稳火、收火初值 45% / 55% / 50%，未学火候眼时没有目标带。
3. 用键盘把起火降到 0%，页面出现夹生形状与文字；用九次方向键恢复 45%，提示回到正好。
4. 确认火候后返回全院，批 B 开始蒸饭，酿艺点到 3；仍未消耗工时。
5. 前柜上架两瓶，后仓从 4 变 2、展位从 0 变 2。推进到两位街坊到柜时，分别得到 15 文。
6. 收工先确认，再显示田 / 酒 / 柜三行，收入 30、开销 8、余钱 182。声望 17、酿艺点 3。
7. 保存今日账页。实际下载的文本已复制为 [实际保存的账页.txt](实际保存的账页.txt)，其三行和数字与当次日结一致。之后为重拍完整画幅，再跑过一次提前收工，批 B 停在待拌曲；两次收入、开销和余钱一致。
8. 依次打开今日、米与酒、酒谱、人手、本季、器物。目标勾选和灯色切换可见，切灯色不扣钱、不推进。
9. 人手页把阿禾安排去曲案，仍显示当前在蒸甑，并显示“已安排去曲案，下个整点到岗”。
10. 在今日页逐一点开水田、浸缸、蒸甑、摊席、曲案、发酵房、压榨、澄清槽、酒窖、调配案、前柜，均进入对应页面，再返回全院。
11. 开启放大文字、减少动效、火候眼预览。回到蒸甑可见三条合适范围；初始状态不会出现这层预览。
12. 蒸甑滑杆有焦点时按 Esc，回到全院，批 B 仍待蒸，钱与工时未变化。

## 规则检查

14 项自动检查全部通过，脚本为 [规则检查.cjs](规则检查.cjs)。重点涵盖：

- 初始资源与三档售价：让利 12、平价 15、讲究 18。
- 正好、夹生、焦糊、低收火、夹生与焦糊同时发生，以及目标带边界。
- 重复搅缸和重复确认不能再次领酿艺点。
- 不确认退出不记火候；没人手不能亲手蒸；交给人手没有亲手加成。
- 上架、回收与成交后四瓶初始甜酒酿保持数量一致。
- 两瓶成交后收工得到 182 文；重开账页不重复扣钱。
- 讲究档客人离开，零成交时收入不凭空出现。
- 误了搅缸仍继续发酵，成色降十二。
- 换岗下个整点生效；无人站柜先等一个工时，回来的人手可完成等待中的买卖。

## 单文件检查与限度

`直接打开.html` 已把三张图、样式、操作放在一个文件中，不需要安装依赖或联网拉取素材。本机预览中实际检查了它的全院、看缸、蒸甑、退出操作和六页账册；画面均正常加载。源码没有外部脚本或样式引用。浏览器自身添加的扩展样式不属于交付文件。

浏览器工具只允许访问网页地址，禁止打开本地文件地址，所以没有用工具验证 `file://` 双击打开；没有绕过这项限制。同一单文件通过本机网页预览跑通，且其图片为内含数据、没有请求正式游戏服务。双击打开的文件结构已经检查，但不把它记成工具已实际完成的动作。

概念图中的模型、人物、饭床和物品本体是静态画面；实际变化来自界面及少量效果示意。未验证正式游戏的三维模型、相机移动、灯光、天气、存档或帧率。样板展示首日操作，不模拟完整种植、全部成品链、28 日成长、批购、升级和家具商店。

# 糯酿界面成果

- 想直接体验：打开 **直接打开.html**。全部场景和操作都在这个文件里。
- 想看所有效果：打开 **效果总览.html**。保留整个文件夹，里面引用了验收画面。
- 想了解为什么这样设计：看 **设计方案.md**。
- 交给设计与制作人员：看 **风格规范.md**、**参考与生成记录.md**，素材文件夹保留了三张独立场景。
- 想查看实际检查结果：看 **验收/验收记录.md**。

推荐体验顺序：先看缸搅一下 → 蒸甑选择米酒并确认火候 → 前柜上架两瓶 → 推进到两次成交 → 收工看三行账页。设置里可以重新体验首日。

这是独立设计样板。场景目前是立体效果图，操作、库存和账页会变化，尚未放进正式游戏。正式规则以原有游戏文档为准。
